# Cadence

A lifestyle companion for goals, daily pillars, gamification, and a living dashboard.

## Run locally

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

## What’s inside

- **Dashboard** — life score, streak, XP/level, weekly pulse chart, pillar balance, badges
- **Goals** — daily check-ins that award XP and advance quests
- **Lifestyle** — five pillars (Sleep, Move, Focus, Connect, Craft) with live dials
- **Quests** — longer challenges with claimable rewards

Progress is saved in `localStorage` under `cadence-life-v1`.
